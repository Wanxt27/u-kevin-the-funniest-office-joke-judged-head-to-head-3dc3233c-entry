## The joke

> I set my out-of-office to 'in a meeting' so people would stop inviting me to meetings — now I have a meeting about my out-of-office.

132 characters. Setup: an out-of-office reply meant to escape meetings. Turn: the escape itself gets a meeting. Punchline last.

## How it works

`main.ts` writes the joke to `/output/entry.txt` (creating `/output` if needed; it never deletes it). The sealed scorer gates on 1–200 UTF-8 characters; a judge model then compares entries two at a time, head to head.

Run it with `node main.ts` and check `/output/entry.txt`.
